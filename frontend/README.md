# Frontend — PoC Tchat

Module frontend du PoC, en Angular.

> ⚠️ Ce dossier est actuellement vide de code : il ne contient que la
> structure attendue. Le code sera ajouté au fil des issues du milestone
> « PoC — Fonctionnalité de tchat ».

## Contenu attendu (à venir)

- Interface de tchat minimale (liste des messages, envoi d'un message)
- Connexion au canal temps réel exposé par le backend
- Respect des principes d'accessibilité définis dans le cahier des
  charges (navigation clavier, restitution correcte par lecteur
  d'écran), même sur ce périmètre restreint

## Conventions

- Un module Angular dédié au tchat (`chat/`), pas de composants du PoC
  mélangés avec une éventuelle structure applicative plus large créée
  ultérieurement.
